# 小孩日记

把你今天对自己说过的话，换一个人念给你听。过一遍普通的一天，六个时刻（07:40 起床、10:30 上午、12:50 午饭、16:00 下午、20:30 晚上、23:40 睡前），每个时刻挑一句你心里先冒出来的话。夜里，你心里那个小孩把这一天写成一篇日记念给你听，再让你改掉其中一句。

它不判对错，也不给你贴类型标签。它只做一件事：把你今天对自己说过的话，换一个人念给你听。

线上地址：https://xiaohai-riji.vercel.app

## 怎么跑

纯前端，零依赖，零外部请求。直接用浏览器打开 `index.html` 就能玩；本地起个静态服务也行：

```
cd 11
npx serve .          # 或 python -m http.server 8080
```

测试（Node 20 以上）：

```
node --test
```

`tests/content.test.js` 检查文案数据的形状（六刻四选项、每刻必有自在、说法不重复、脸都是 8×8）。`tests/copy.test.js` 用同一个陈列馆里的「去腔」（`../10/engine.js`）跑我们自己的文案，要求计入密度的套路命中为 0。

地址后面加 `?fresh` 可以不读不写存档，方便反复试。

## 文件

- `index.html`：页面骨架与全部样式（内联）。
- `app.js`：渲染与状态，不含任何文案。
- `content.js`：全部文案与数据（六刻情境、选项、日记句、练习提示、结语、像素脸）。
- `og.jpg`、`favicon.svg`：分享卡与图标，都是像素脸。
- `tests/`：见上。

## 说法来源与致谢

这页里的六种说法（吓自己、逼自己、否定自己、推开别人、先忙完再说，以及自在）来自丛非从《养育你内心的小孩》（万卷出版公司，2022）对五种心理需要的分析：安全感、自由、价值感、亲密、意义感。书里的原词是「自我恐吓」「自我强迫」「自我否定」「拒绝爱」。

情境、选项和日记句都是这页自己写的，不是书里的句子。这页不是测评，不构成任何诊断，和作者、出版社没有关系。想读原书，去任何一家书店搜书名就行。

那张 8×8 的琥珀色像素脸来自作者自己的另一个小东西「聆宠」。这页是小世界陈列馆（https://xiaoshijie.vercel.app）里的一件。

## 隐私

- 什么都不会上传。页面加载后除本站文件外没有任何网络请求，没有统计、没有埋点。
- 只用 localStorage 存一项 `xh.diaries`：一个数组，最新的在前，最多留 7 篇（每篇是日期、六个选择的下标、睡前改的那句）。封面的「看上次的日记」打开最新一篇，日记页顶部有多篇时可以切换。清掉浏览器数据就没了。v1 存的 `xh.diary`（单篇）第一次打开时会并进数组，然后删掉旧键。
- 「复制这篇日记」只把纯文本放进你的剪贴板，去哪由你决定。
